# Security policy

Cénacle shows third-party websites with signed-in sessions, so a flaw can expose a user's
accounts. Please report security problems **privately**.

## How to report

Use GitHub's private reporting: **Security → Report a vulnerability** on the
[repository page](https://github.com/Jeromearsene/cenacle-AI/security/advisories/new).
Do not open a public issue or pull request for a vulnerability.

Please include the app version, your system, and the steps to reproduce.

## What is in scope

- The application code in this repository (main process, preloads, interface).
- The configuration of the sessions, permissions and windows.

The websites displayed by the app (Claude, ChatGPT, Gemini…) belong to their owners: report
their flaws to them.

## Supported versions

Only the latest release receives fixes.
